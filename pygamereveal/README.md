# Apresentação Pygame

Abra `index.html` no navegador, ou sirva esta pasta com `python -m http.server`. Use ←/→ para mudar de módulo, ↑/↓ para percorrer o conteúdo, M para abrir o índice e Alt+C (Option+C no macOS) para copiar o primeiro código do slide. Cada bloco de código também tem um botão de cópia.

Para atualizar a apresentação após editar `../resumos/pygame.md`, execute `python gerar.py`. A geração requer `pandoc` e `beautifulsoup4`.
